# Password Strength Analyzer

## Objective
This project checks the strength of passwords using:
- Length validation
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Features
- Detects Weak, Medium, and Strong passwords
- Gives suggestions to improve password security
- Beginner-friendly cybersecurity project

## Technologies Used
- Python
- Regular Expressions (re module)
